##


Iniciei o curso de Engenharia de Software com o objetivo de realizar uma transição de carreira para a área de tecnologia e construir uma trajetória profissional sólida no desenvolvimento de software. Tenho maior afinidade com Front-end, área na qual venho desenvolvendo meus conhecimentos e que desperta meu maior interesse. Ao mesmo tempo, busco compreender o desenvolvimento de aplicações web de forma mais ampla, adquirindo conhecimentos sobre Back-end, APIs, integração entre sistemas e bancos de dados. Também tenho interesse em conhecer e explorar a área de Dados.
Atualmente, além da graduação, realizo cursos voltados ao desenvolvimento Full Stack pela Rocketseat, com o objetivo de complementar minha formação acadêmica, ampliar minha visão sobre desenvolvimento web e fortalecer minha base técnica. Também venho realizando cursos livres na área de Dados, incluindo conteúdos relacionados a Business Intelligence (BI), Analytics e Data Visualization.
